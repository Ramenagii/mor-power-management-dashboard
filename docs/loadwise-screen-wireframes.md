# Loadwise Screen Wireframes

Editable diagrams.net / draw.io wireframes for the deployed Loadwise dashboard:

- `loadwise-screen-wireframes.drawio`

## Included Pages

1. Dashboard Wireframe
2. Policies Wireframe
3. Hardware Components Wireframe
4. Mobile Dashboard Wireframe
5. Mobile Policies Wireframe
6. Mobile Hardware Components Wireframe

## Basis

These wireframes are based on the deployed Loadwise web app and the provided screenshots for:

- Dashboard overview and six outlet cards
- ECA policy repository
- Hardware component architecture

The mobile pages reflect the app's responsive behavior: stacked header, stacked cards, single-column outlet cards, and vertically arranged policy/hardware sections.

## How To Open

Open `loadwise-screen-wireframes.drawio` in:

- diagrams.net / draw.io desktop
- https://app.diagrams.net

You can then export the pages as PNG/SVG/PDF for Chapter 3 or defense slides.
